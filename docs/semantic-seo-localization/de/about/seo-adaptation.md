## Target Keywords
| Keyword | Rationale (only if it differs from a literal translation) |
|---|---|
| Größenvergleich | Standard German search term for "height comparison"; a literal word-for-word translation ("Höhenvergleich") is rarely used by German searchers for comparing people/objects — "Größe" (size/stature), not "Höhe" (elevation), is the term Germans use for a person's height. |
| Promi Größenvergleich | German searchers use "Promi" (colloquial short form of "Prominente") rather than the formal "Prominente" when searching for celebrity comparisons — matches actual query phrasing, not a literal "Prominenten-Größenvergleich." |
| Größenunterschied Rechner | Maps to "Height Difference Calculator"; "Rechner" (calculator) is the conventional German suffix for tool pages, not a translation of "calculator" placed before the noun as in English. |
| Endgröße berechnen | Maps to "Height Predictor"; German searchers query "Endgröße" (final/adult height) rather than a literal "Größenvorhersage," which reads as awkward machine-translation German. |
| Idealgewicht Rechner | Maps to "Ideal Body Weight Calculator"; "Idealgewicht" is the single compound noun German speakers search for, not a literal "ideales Körpergewicht Rechner." |
| Durchschnittsgröße nach Land | Maps to "Average Height by Country"; direct compound-noun phrasing matches German search conventions (compounding preferred over prepositional phrases). |
| Körpergröße aus Foto schätzen | Maps to "Image to Height"; describes the action (estimating height from a photo) the way a German searcher would phrase a query, rather than a literal "Bild zu Größe." |
